# SafarEase — Frontend (Mock)

This is a mock frontend application for SafarEase — a smart urban travel app built with React + Vite + Tailwind CSS. It uses mock JSON data and requires no backend.

Getting started

1. Install dependencies:

```bash
npm install
```

2. Run dev server:

```bash
npm run dev
```

Project structure

- `src/components` — UI components
- `src/pages` — App pages (Home, Results, Details, Rewards, Profile)
- `src/data` — mock route data
- `src/main.css` — Tailwind entry + variables

Design notes

- Colors and UI follow the provided palette (primary: #6FCF97, secondary: #A8E6CF, accent: #219653)
- Mobile-first responsive design

Next steps

- Run `npm install` and `npm run dev` to open the app locally at `http://localhost:5173`.
